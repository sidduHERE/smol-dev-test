# Solana Prediction Market

This is a unique, cool, transient, and rich website built using Next.js for Solana chain dapp for prediction market. You can see BTC price chart using TradingView iframe and every 5 min rounds expired ones are disabled in a carousel and new ones are disabled saying there are gonna come and the current one with options to go long or short.

## Features

- BTC price chart using TradingView iframe
- Prediction market with options to go long or short
- Carousel of rounds with expired ones disabled and upcoming ones announced

## Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/your-repo/solana-prediction-market.git
cd solana-prediction-market
npm install
```

## Running the App

Start the Next.js server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
